
## Basic ChatGPT Prompts

**Prompt 1:** Write a short study plan for exams.  
**Output 1:** Study 2 topics daily, take short breaks, and revise every night.

**Improved Prompt 1:** Create a 3-day exam revision plan for a college student with 2-hour daily slots.  
**Output 1:** Day 1: Core concepts (2 hrs). Day 2: Practice problems (2 hrs). Day 3: Full revision & quick notes (2 hrs).

**What Changed:** Added timeframe (*3-day*, *2-hour slots*) and target audience (*college student*) to get a practical schedule.
